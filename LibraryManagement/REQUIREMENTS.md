# Library Management System

## Overview

A simple Java console application that models a Library Management System using Object-Oriented Programming principles.

The project demonstrates how objects collaborate to perform operations such as adding books, borrowing books, returning books, and displaying available books.

---

## Features

- Add books to the library
- Remove books
- Search books by ID
- Borrow books
- Return books
- Display all books
- Display only available books

---

## Concepts Practiced

- Classes & Objects
- Encapsulation
- Composition
- Constructors
- ArrayList
- Method Design
- Object Collaboration
